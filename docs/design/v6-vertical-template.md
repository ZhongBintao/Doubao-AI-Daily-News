- 状态：**视觉方向暂定通过**（2026-11-03，用户确认）；**已实现**为生产模板 `ai_morning_brief/template/v6/index.html`；2026-11-03 第二轮修改见第 10 节
- 适用平台：TikTok、小红书（9:16 竖屏）
- 样张：[`v6-vertical-preview/`](v6-vertical-preview/)（`template.html` + `data.js`，截图见 `screenshots/`）

## 1. 设计原则

1. **基于原 v5 模板演进，不另起风格。** 原模板“标题 + 信息卡”的结构对不同类型新闻适配性强，保留其结构与视觉语言。
2. **通用优先于单条效果。** 版式不依赖某条新闻是否有数字、Logo 或特定结构；所有适配（字号、紧凑、分页、换行）都由通用规则完成，不为单条新闻手调。
3. **照顾能力较弱的写稿模型。** 模型只填固定字段和少量可选标记，不做版式决策。

## 2. 保留自 v5 的元素

- 暖米白纸张底 `#f7f4ee` + 72px 网格纹理 + 右上角陶土橙径向光晕、同心圆装饰
- 陶土橙标题、深青标签、白色圆角信息卡（卡片底 `#fffefa`、细描边、柔和投影）
- 卡片图标（由正文关键词自动推断，不由模型指定）
- 深色圆角字幕条（`rgba(32,40,43,.93)`，白字）
- 全片字体 `Noto Sans SC`

## 3. 相对 v5 的改动

| 项 | v5 | v6 |
|---|---|---|
| 画幅 | 1920×1080 | **1080×1920** |
| 导航 | 顶部 66px 新闻标题导航 | 左上 `AI每日早报 日期` 字标 + 右上 `头条/快讯 n/N` 与分段进度条（全片一份，不随场景淡入淡出） |
| 开场 | 栏目名大字 + 问候语 + 概览页 | **开头钩子页**（见 4.1），概览页建议去掉（待确认） |
| 卡片排列 | 多列网格，每页 3–5 张 | **单列竖排，每页最多 4 张，均衡分页** |
| 卡片主体名 | 每张卡重复 | 只在类别标签旁出现一次（方形 Logo 配名字，横版字标单独出现，无 Logo 用文字） |
| 卡片强调色 | 按卡片序号轮换 5 色 | **按新闻类别固定一种**（见 5） |
| 讲解同步 | 未实际生效 | 本页卡片一起出现：正在讲的展开并描边高亮，其余收起为“标签 + 小标题”（未讲的 0.5、讲过的 0.78 透明度） |
| 字距 | 标题 -0.09em、栏目名 -0.12em（字形挤压） | 标题 -0.02 ~ -0.03em |
| 中文换行 | 按字断行，常见孤字、拆词 | 按词换行 + 均衡换行（见 6） |

## 4. 画面类型

### 4.1 开头钩子（0–3 秒，只用于头条）

- 行 1：`今日头条` 标签（类别强调色）+ 主体 Logo 白色胶囊；无 Logo 时退回主体名文字胶囊
- 行 2：钩子大字，`118px → 76px` 自动缩放，最多 4 行；可用一对 `【】` 标出一处重点（显示为强调色）
- 强调色短横线
- “发生了什么”卡片：一句客观事实
- 内容在可用区域内垂直居中

### 4.2 头条卡片页

- `头条` 标签 + 类别小标题（深青）+ 主体胶囊 → 新闻标题（类别强调色，`66px → 50px`，最多 3 行）→ 卡片列
- 卡片：图标（由隐藏的 angle 决定，9 种角度 9 个图标）+ 钩子小标题（墨黑，46px，由写稿 AI 按内容写，不显示栏目标签）+ 正文（35px）；正文中可用一对 `【】` 高亮数字
- 手风琴式讲解：本页卡片一起出现，正在讲的展开，其余只显示钩子小标题，整页像一份悬念提纲
- 分页按“一张展开 + 其余收起”计算，并均衡分配（5 张 → 3 + 2）；单张展开仍放不下时先切紧凑样式，**永不截断**

### 4.3 快讯页（每条 12–20 秒）

- `快讯` 标签（深青）+ 类别小标题 + 主体胶囊 → 标题（`72px → 54px`，最多 3 行）→ “要点”卡 + “为什么值得关注”卡（40px 正文，随旁白依次出现并高亮）
- 内容垂直居中

### 4.4 结尾页

- 至少 5.5 秒：字标 → “今天讲了”回顾（每条新闻一行，头条/快讯标签）→ `关注我，每天看懂 AI 大事。`（资讯来源不在画面上显示，写在发布文案里）

## 5. 配色（2026-11-04 改为方案 A，按版块分色）

| 用途 | 颜色 |
|---|---|
| 头条（钩子、头条页、回顾里的头条标签） | 陶土橙 `#D0643A`，标题深色 `#A5441D`，浅底 `rgba(208,100,58,.13)` |
| 快讯（快讯页、回顾里的快讯标签） | 藏青 `#2D5B8C`，标题深色 `#1D3F66`，浅底 `rgba(45,91,140,.11)` |
| 共用 | 米白底 `#F7F4EE`、卡片 `#FFFEFA`、正文墨黑 `#1F2629`、辅助字灰 `#737A77`、描边 `#E3DED4` |
| 品牌 | 字标、结尾页用陶土橙 |

- 新闻类别（模型、行业、论文……）只作灰色文字标签，不再决定颜色（原来按类别配色，导致行业类头条整页深青、与快讯撞色，同屏最多 4 种色相）
- 背景右上角光晕随版块变化：头条偏暖、快讯偏冷
- 顶部进度条每一格保持所属版块颜色，一眼看出今天有几条头条、几条快讯
- 数字高亮用所在版块的深色 + 浅底

## 6. 布局与排版规则

- 画布 1080×1920；左边距 64px，**右边距 150px**（避开平台右侧操作栏）
- 字标与进度条位于 y=196–260；内容区 y=300 至距底 572px（约 y=1348）
- 字幕条顶部 y=1372，46px 字号，最多 2 行（每行 ≤16 单位），一个圆角框按文字宽度收缩，句末标点不显示；钩子页不显示字幕（大字已在画面上，SRT 里仍保留）；其下约 400px 留给平台标题区
- 按词换行（标题、卡片、字幕、回顾列表）：使用 `Intl.Segmenter('zh')` 分词，词内不断行；英文/数字/连字符串（如 `S-1`、`Qwen3.5-0.8B`）不拆；≤18 字符的英文专名（`Hugging Face`、`Mistral Large 4`）不拆；数字 + 单字量词（如 `九个`、`6 倍`）不拆；单字后缀与助词粘前（`量化版`、`预期的`），单字前缀粘后（`大模型`）
- 标题、钩子、字幕、段落使用 `text-wrap: balance`，避免末行孤字

## 7. 写稿模型需要填写的字段

沿用 v5 的标题与卡片字段，新增两项：

| 字段 | 约束 |
|---|---|
| `hook` | 20 字以内，可含一对 `【】` 重点标记 |
| `keyfact`（发生了什么） | 一句客观事实 |
| `title` | 新闻标题 |
| `cards[].label / headline / body` | 同 v5；`body` 可含一对 `【】` 高亮 |
| `flash_title / flash_body` | 快讯标题与要点 |

所有事实仍须回溯到 AIHOT 来源；字段结构与示范案例将随写稿 skill 一起提供。

## 10. 2026-11-03 第二轮修改（第一期实跑后）

起因：第一期 44 秒成片内容单薄（头条只是复述一句话摘要，快讯只有一句），同时有若干画面缺陷。用户决定：**只用 AIHOT 网站本身的数据，不打开原文链接**；条数按当天内容灵活决定；时长上限 3 分钟；内容质量优先于短视频节奏。

内容：

- 素材包（`ai_morning_brief/material.py`）：AIHOT 综述 + 各来源报道 + 站内搜索到的同事件报道 + 相关事件/此前报道；按 rich / medium / thin 决定能否做头条和字数预算
- 同一故事线合并（AIHOT 相关事件或来源报道互相指向时）
- 节目单：头条 ≤3、快讯 ≤5，按时长估算裁剪到 3 分钟；重磅但素材少的降为快讯
- 导演稿 6.1：卡片标签固定 9 选 1，素材足够时必须有“各方说法 / 背景 / 为什么重要 / 对你的影响”；快讯 = point + why；字数下限随素材浮动；小标题与正文不能重复；素材里的“尚未验证”必须保留

画面：

| 问题 | 修改 |
|---|---|
| 转场时顶栏重影 | 顶栏移出场景，全片一份，只切换进度 |
| 字幕拆词（“增 / 长”）、句末逗号不统一 | 字幕也按词换行；去掉句末标点；单框按文字宽度收缩 |
| 卡片/开头大字换行拆词（“量化 / 版”“Hugging / Face”“大 / 模型”） | 增加前后缀、助词、英文专名规则 |
| 三张卡图标相同 | 图标由标签决定 |
| 下半屏大片空白、字小 | 卡片字号放大（正文 35px、小标题 46px）；手风琴式整页卡片；均衡分页 |
| 快讯页 5 秒静止、一张卡 | 两张卡随旁白出现并高亮 |
| 高亮卡片右移侵入安全区 | 去掉右移 |
| Logo 太小、认不出 | 方形 Logo 配名字；白色透明 Logo 自动改深色 |
| 钩子页字幕与大字重复 | 钩子页不显示字幕 |
| 结尾只有关注语 | 增加“今天讲了”回顾 |
