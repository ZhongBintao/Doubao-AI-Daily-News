# AI每日早报 · v6 竖屏模板设计记录

- 状态：**视觉方向暂定通过**（2026-11-03，用户确认）
- 适用平台：TikTok、小红书（9:16 竖屏）
- 样张：[`v6-vertical-preview/`](v6-vertical-preview/)（`template.html` + `data.js`，截图见 `screenshots/`）
- 重新渲染样张：`node docs/design/v6-vertical-preview/render.js <输出目录>`

## 1. 设计原则

1. **基于原 v5 模板演进，不另起风格。** 原模板“标题 + 信息卡”的结构对不同类型新闻适配性强，保留其结构与视觉语言。
2. **通用优先于单条效果。** 版式不依赖某条新闻是否有数字、Logo 或特定结构；所有适配（字号、紧凑、分页、换行）都由通用规则完成，不为单条新闻手调。
3. **照顾能力较弱的写稿模型。** 模型只填固定字段和少量可选标记，不做版式决策。

## 2. 保留自 v5 的元素

- 暖米白纸张底 `#f7f4ee` + 72px 网格纹理 + 右上角陶土橙径向光晕、同心圆装饰
- 陶土橙标题、深青标签、白色圆角信息卡（卡片底 `#fffefa`、细描边、柔和投影）
- 卡片图标（由正文关键词自动推断，不由模型指定）
- 深色圆角字幕条（`rgba(32,40,43,.93)`，白字）
- 全片字体 `Noto Sans SC`

## 3. 相对 v5 的改动

| 项 | v5 | v6 |
|---|---|---|
| 画幅 | 1920×1080 | **1080×1920** |
| 导航 | 顶部 66px 新闻标题导航 | 左上 `AI每日早报 日期` 字标 + 右上 `头条/快讯 n/N` 与分段进度条 |
| 开场 | 栏目名大字 + 问候语 + 概览页 | **开头钩子页**（见 4.1），概览页建议去掉（待确认） |
| 卡片排列 | 多列网格，每页 3–5 张 | **单列竖排，每页最多 3 张** |
| 卡片主体名 | 每张卡重复 | 只在标题下出现一次（Logo 或文字标签） |
| 卡片强调色 | 按卡片序号轮换 5 色 | **按新闻类别固定一种**（见 5） |
| 讲解同步 | 未实际生效 | 正在讲的卡片高亮并右移 10px，讲过的卡片透明度 0.7 |
| 字距 | 标题 -0.09em、栏目名 -0.12em（字形挤压） | 标题 -0.02 ~ -0.03em |
| 中文换行 | 按字断行，常见孤字、拆词 | 按词换行 + 均衡换行（见 6） |

## 4. 画面类型

### 4.1 开头钩子（0–3 秒，只用于头条）

- 行 1：`今日头条` 标签（类别强调色）+ 主体 Logo 白色胶囊；无 Logo 时退回主体名文字胶囊
- 行 2：钩子大字，`118px → 76px` 自动缩放，最多 4 行；可用一对 `【】` 标出一处重点（显示为强调色）
- 强调色短横线
- “发生了什么”卡片：一句客观事实
- 内容在可用区域内垂直居中

### 4.2 头条卡片页

- 类别小标题（深青）→ 新闻标题（类别强调色，`68px → 50px`，最多 3 行）→ 主体 Logo/文字胶囊 → 卡片列
- 卡片：图标 + 标签（深青）+ 小标题（强调色深色）+ 正文；正文中可用一对 `【】` 高亮数字
- 卡片超出可用区时：先切换紧凑样式（内边距、字号缩小），仍超出则自动分页（剩余卡片进入下一页），**永不截断**

### 4.3 快讯页（每条 10–15 秒）

- `快讯` 标签（深青）+ 类别小标题 → 标题（`76px → 54px`，最多 3 行）→ 主体胶囊 → 一张“要点”卡
- 内容垂直居中

### 4.4 结尾页

- 建议保留 2–3 秒“关注”页（待确认，未出样张）

## 6. 布局与排版规则

- 画布 1080×1920；左边距 64px，**右边距 150px**（避开平台右侧操作栏）
- 字标与进度条位于 y=196–260；内容区 y=300 至距底 572px（约 y=1348）
- 字幕条顶部 y=1372，46px 字号，最多 2 行；其下约 400px 留给平台标题区
- 按词换行：使用 `Intl.Segmenter('zh')` 分词，词内不断行；英文/数字/连字符串（如 `S-1`、`Qwen3.5-0.8B`）不拆；数字 + 单字量词（如 `九个`、`6 倍`）不拆
- 标题、钩子、字幕、段落使用 `text-wrap: balance`，避免末行孤字

## 7. 写稿模型需要填写的字段

沿用 v5 的标题与卡片字段，新增两项：

| 字段 | 约束 |
|---|---|
| `hook` | 20 字以内，可含一对 `【】` 重点标记 |
| `keyfact`（发生了什么） | 一句客观事实 |
| `title` | 新闻标题 |
| `cards[].label / headline / body` | 同 v5；`body` 可含一对 `【】` 高亮 |
| `flash_title / flash_body` | 快讯标题与要点 |

所有事实仍须回溯到 AIHOT 来源；字段结构与示范案例将随写稿 skill 一起提供。

## 8. 待定事项

- 动效：卡片依次出现、高亮切换、换场过渡（样张为静态）
- 生产渲染环境需离线提供 `Noto Sans SC` 字体（样张通过 Google Fonts 加载）
